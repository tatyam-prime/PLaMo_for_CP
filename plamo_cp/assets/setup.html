PLaMo 3 Translate の利用条件

本ツールは，PLaMo 3 Translate をダウンロードして使用します．

PLaMo 3 Translate を使用するにあたり，PLaMoコミュニティライセンス契約 に同意・契約する必要があります．特に以下の点に注意してください．

  • 訳文を公表する際には，PLaMo 3 Translate により翻訳されたことを明示すること．
  • 未成年者は，親権者又は法定代理人に契約の確認を取ること．

ブラウザーの設定

Tampermonkey に翻訳スクリプトをインストール・有効化すると、この場所に自動翻訳・用語集などの設定が表示されます。導入後はこのページを開き直してください。

導入・利用上の注意

Tampermonkey を入手

最初に Tampermonkey をブラウザーへ追加し、上の「翻訳スクリプトをインストール」から追加します。翻訳中はこのアプリを開いたままにしてください。

Chrome では、拡張機能画面の Tampermonkey の詳細から「ユーザースクリプトを許可」を有効にしてください。見つからない場合は 公式の設定手順をご確認ください。

以前の PLaMo for CP の Chrome 拡張をお使いの場合は、無効にしてから問題ページを開き直してください。
