# PLaMo for CP

**競技プログラミングの問題文を、数式を保ったまま日本語に。**

[PLaMo 3 Translate](https://huggingface.co/pfnet/plamo-3-translate-2b-MLX-4bit) を手元のパソコンで動かす、非公式の翻訳ツールです。ローカルアプリと [Tampermonkey](https://www.tampermonkey.net/) スクリプトを組み合わせて使います。翻訳する文章を外部の翻訳APIへ送信しません。

Built with PLaMo.

> **現在は配布準備中のテスト版です。** インストーラーの公開はまだ行っていません。Apple Silicon Macで動作を確認しています。Windows版はビルド定義を用意していますが、実機確認は未完了です。手元で生成したMacアプリはmacOS 27以上が必要で、一般配布用の署名・公証は未実施です。

## できること

- Codeforces・CodeChefなどの問題文を、ページ上で翻訳する。
- KaTeX・MathJax・MathMLの数式、変数、画像、コード、サンプル入出力を保つ。
- Macでは生成途中から訳文を表示する。翻訳中でも原文へ切り替えられる。
- 800M・2B・8Bからモデルを選び、用語集を編集する。
- 一般の記事・arXivのHTML版や、貼り付けた文章も翻訳する。

## 利用を始める

配布アプリを利用する場合の手順です。ソースから起動する場合は[開発者向けの手順](#ソースから起動する)を参照してください。

1. **PLaMo for CPアプリ**を開きます。ブラウザーに管理画面が開きます。
2. モデルの利用条件を確認し、必要なら保存先を選んで **「ダウンロード」** を押します。標準モデルは **2B** です。
3. 取得が終わったら **「このモデルを使う」** を押します。
4. ブラウザーに [Tampermonkey](https://www.tampermonkey.net/) を追加し、管理画面の **「翻訳スクリプトをインストール」** を押します。
5. 問題ページを開き直し、翻訳バーの翻訳アイコンを押します。

Chromeでは拡張機能の設定でユーザースクリプトの実行許可が必要です。[詳しい導入手順とブラウザー設定](userscript/README.md#利用する)を参照してください。

翻訳中はアプリを起動しておいてください。アプリの管理画面を表示したり、翻訳モデルを選んだりするだけでモデルをダウンロードすることはありません。

## 対応ページ

| サイト | 対象 |
| --- | --- |
| [Codeforces](https://codeforces.com/) | 英語の問題文 |
| [CodeChef](https://www.codechef.com/) | 英語の問題文、ページ内の問題切り替え |
| [CSES](https://cses.fi/problemset/)・[Kattis](https://open.kattis.com/) | 問題文 |
| [Repovive](https://repovive.com/) | 通常の問題文 |
| [UOJ](https://uoj.ac/) | 中国語の問題文 |
| [TLX](https://tlx.toki.id/) | 英語・インドネシア語の問題文 |
| [Project Euler](https://projecteuler.net/) | 問題文 |
| [arXiv HTML](https://arxiv.org/) | 論文のHTML版（`/html/`） |

一般ページでは、Tampermonkeyのメニューから **「このページを翻訳」** を選びます。よく使うサイトは管理画面にドメイン・URLパターンを登録すると、翻訳バーを表示できます。自動翻訳はサイトごとに設定でき、初期状態はオフです。

RepoviveのMath Contest / Math Roundでは、翻訳バーを自動表示せず、自動翻訳も開始しません。手動操作は利用できます。**コンテスト中の利用可否は、そのコンテストの規則を確認してください。**

PDFはブラウザー内で直接翻訳しません。文章をコピーし、アプリまたはTampermonkeyのメニュー **「テキストを翻訳」** から対訳ページへ貼り付けて使えます。コピー時に数式・添字・指数が崩れることがあるため、原本を確認してください。iframe内の文書やcanvas内の文字も対象外です。

## モデルと動作環境

| モデル | Macでの重み容量 | Windowsでの重み容量 | ツールが要求するメモリ |
| --- | ---: | ---: | ---: |
| 800M（0.8B） | 約0.98 GB | 約0.57 GB | 4 GB以上 |
| **2B（標準）** | 約2.41 GB | 約1.81 GB | 8 GB以上 |
| 8B | 約6.07 GB | 約5.28 GB | 16 GB以上 |

重みのほかにOS・実行環境・翻訳中のメモリが必要です。表のメモリは本ツールの設定で、モデル提供元の動作保証ではありません。初回に検出したメモリが不足する場合は800Mを選びます。

- **Mac：** Apple Silicon向け。公式MLX 4bitモデルを使い、生成途中の訳文を表示します。Intel Macは対象外です。必要なmacOSのバージョンは配布物により異なり、現在のローカルビルドはmacOS 27以上です。
- **Windows：** x64向けのビルド定義を用意しています。公式GGUF Q4_K_Mとllama.cppのCPU版を使い、段落の完了後に表示します。Windows実機でのビルド・翻訳は未確認です。

800Mと2Bの実翻訳を確認しています。8Bの品質・速度は未評価です。

## 設定とデータの管理

アプリの管理画面で次を設定できます。

- モデルの保存先を選ぶ・開く、モデルごとのダウンロード・使用・メモリ解放・削除。
- 翻訳バーを表示するサイト、サイトごとの自動翻訳、用語集。
- モデルごとの **「同時に翻訳する段落数」**。1～16から選択でき、標準は800M＝4、2B＝4、8B＝8です。
- 訳文キャッシュの容量上限と一括消去。標準1 MiB、256 KiB～64 MiBから選べます。

翻訳バーはつまみをドラッグして動かせます。位置は保存されます。**「設定をデフォルトに戻す」** はブラウザーの設定を初期化し、モデルファイルと訳文キャッシュは残します。

モデルの取得中も、取得済みの別モデルを使えます。取得が終わっても使用中のモデルは切り替わりません。保存先を変更しても、以前のモデルファイルを自動移動しません。元のフォルダーを選び直せば再利用できます。

用語集の初期値は、modular inverse＝逆元、proper prefix＝真の接頭辞、parallel edge＝多重辺、prefix sum＝累積和、jury＝ジャッジ、subarray＝連続部分配列、increment＝インクリメント、pairwise disjoint＝互いに交差しない、sequence＝列、visualizer＝ビジュアライザ、forest＝森です。**保存した一覧だけを使い、空にして保存すれば用語集なしで翻訳します。** 一般文書では競プロ用の初期用語を除き、追加・変更した語を使います。

## プライバシーと翻訳の限界

本文はパソコン内のアプリ（`127.0.0.1:8765`）へ送信し、ローカルで翻訳します。モデル取得時はHugging Faceへ、Windowsの実行環境を別途取得する場合は公式GitHub Releasesへ接続します。Tampermonkeyや閲覧サイト自身の通信は、それぞれの設定・利用条件に従います。

訳文キャッシュは **保存から7日** で再利用の対象外となり、アプリの起動・利用時に期限切れを削除します。容量上限を超えると古い利用分から削除します。保存先は `~/.cache/plamo-cp/translations.sqlite3`、アプリ設定は `~/.config/plamo-cp/settings.json` です。モデルの保存先は管理画面で確認できます。ブラウザーの設定はTampermonkeyに保存します。キャッシュは暗号化しないため、共有パソコンで機密文書を扱う場合は保存データにも注意してください。

通常のHTTPアクセスログは出力しません。ログの保存先は `~/.cache/plamo-cp/logs/` です。Macのアプリログは合計最大256 KiB、Windowsは関連ログを含め最大768 KiBに制限します。アプリを削除しても、モデル・設定・キャッシュは残ることがあります。

APIはこのパソコン専用です。LANやインターネットへ公開しないでください。Macでは公式の固定リビジョンに含まれるモデル実装を実行するため、信頼できる保存先を使ってください。

数式や書式の識別子が壊れた訳は確定せず、その部分の原文を残します。ただし、条件・否定・順位などの誤訳や人名の表記揺れをすべて検出できるわけではありません。必要に応じて原文へ切り替えて照合してください。

## ソースから起動する

開発者向けです。Python 3.11～3.13と [uv](https://docs.astral.sh/uv/) を使います。ブラウザーテストにはNode.jsとインストール済みのChromeも必要です。

```sh
uv sync --locked
node scripts/build_userscript.mjs
uv run plamo-cp serve
```

[管理画面](http://127.0.0.1:8765/)を開き、利用条件を確認してモデルを取得し、翻訳スクリプトをインストールします。依存パッケージやモデルの取得には通信・空き容量が必要です。

```sh
uv run pytest -q
uv run ruff check plamo_cp tests scripts
npm ci
npm test
```

アプリへのパッケージ化は、[Mac](packaging/macos/README.md)・[Windows](packaging/windows/README.md)のビルド手順を参照してください。実モデルによる評価は自動テストとは別です。
