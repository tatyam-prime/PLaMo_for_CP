# PLaMo for 競プロ

競プロの問題文を、数式や書式を保ったまま日本語に翻訳する非公式ツールです。[PLaMo 3 Translate](https://huggingface.co/pfnet/plamo-3-translate-2b-MLX-4bit) を自分のパソコンで動かし、Tampermonkey でページに訳文を表示します。本文を外部の翻訳 API へ送りません。

## ダウンロード

[Releases](../../releases) の **Assets** から、使うパソコンに合うファイルを選んでください。アプリ版の利用には Python・Node.js・ターミナル操作は不要です。

| パソコン | 配布ファイル | 導入方法 |
| --- | --- | --- |
| Mac（Apple Silicon） | `PLaMo-for-競プロ-macOS-AppleSilicon.zip` | 展開してアプリを「アプリケーション」へ移動 |
| Windows（x64） | `PLaMo-for-競プロ-Windows-Setup.exe` | インストーラーを実行 |

**現在の Mac ビルドは macOS 27 以降向け・未公証です。Windows 版は実機未検証です。** 各リリースの対応 OS・署名・検証状況を確認してください。

Mac の起動時に開発元の確認が表示される場合は、[Apple の説明](https://support.apple.com/ja-jp/102445)を参照してください。

## 使い始める

以下は Chrome を使う手順です。モデルの初回ダウンロードにはインターネット接続と、数 GB の空き容量が必要です。

1. **PLaMo for 競プロ** アプリを開きます。ブラウザーに設定・管理画面が開きます。
2. 利用条件を確認し、モデルの保存先を選んで **「ダウンロード」** を押します。標準は **2B**。容量を抑えたい場合は **800M** を選べます。
3. 取得が終わったら **「このモデルを使う」** を押します。
4. ブラウザーに [Tampermonkey](https://www.tampermonkey.net/) を追加します。Chrome の拡張機能設定で **「ユーザースクリプトを許可」** を有効にしてください。[公式の設定手順](https://www.tampermonkey.net/faq.php?locale=ja&q=Q209)
5. アプリの管理画面で **「翻訳スクリプトをインストール」** を押し、Tampermonkey の画面でインストールします。
6. 問題ページを開き直し、翻訳バーの翻訳アイコンを押します。

翻訳中も原文と訳文を切り替えられます。バーはドラッグで移動でき、位置を保存します。翻訳中はアプリを起動したままにしてください。アプリが止まっている場合は、バーの **「起動」** から開けます。Windows でこのリンクを使うには、インストーラーでの導入が必要です。

## 対応ページ

[Codeforces](https://codeforces.com/)・[CodeChef](https://www.codechef.com/)・[CSES](https://cses.fi/)・[Kattis](https://open.kattis.com/)・[Repovive](https://repovive.com/)・[UOJ](https://uoj.ac/)・[TLX](https://tlx.toki.id/)・[Project Euler](https://projecteuler.net/)・[arXiv の HTML 版](https://arxiv.org/html/)。

一般のページも、Tampermonkey のメニュー **「このページを翻訳」** から利用できます。よく使うサイトは管理画面で追加できます。サイトごとのバー表示・自動翻訳も設定でき、自動翻訳は初期状態では OFF です。

PDF は文章をコピーし、メニューの **「テキストを翻訳」** から対訳ページへ貼り付けてください。ブラウザー内の PDF を直接翻訳する機能はありません。コピーで数式が崩れる場合は原本と見比べてください。

コンテスト中の AI 翻訳の利用可否は、各サイト・大会の規則に従ってください。Repovive の Math Contest / Math Round では、バーを自動表示せず、自動翻訳も開始しません。

## モデルと設定

| モデル | Mac / Windows のダウンロード容量 | 搭載メモリの目安 |
| --- | ---: | ---: |
| 800M | 約 0.98 / 0.57 GB | 4 GB 以上 |
| **2B（標準）** | 約 2.41 / 1.81 GB | 8 GB 以上 |
| 8B | 約 6.07 / 5.28 GB | 16 GB 以上 |

上記はモデル選択の目安です。重みとは別に実行用メモリが必要で、翻訳の並列数や文章の長さによって使用量は変わります。Windows の GPU メモリ条件・速度は未検証です。

- **モデルの管理：** 保存先の変更、ダウンロード、使用、削除ができます。別のモデルを取得中も、取得済みのモデルを使えます。
- **翻訳の並列数：** 大きくすると、一度に行う計算量はほぼ比例して増え、メモリ使用量は少し増えます。個々の翻訳は少し遅くなりますが、全体の翻訳を効率よく進められます。
- **用語集：** 初期値は競プロ向けの12語です。自由に編集でき、空にして保存すると用語集なしで翻訳します。一般文書では初期語を除き、追加・変更した語を使います。
- **推論の稼働率：** 低い値ほど翻訳速度を抑えて負荷を下げます。長い文書の翻訳でファンの音が気になるときに調整できます。
- **訳文キャッシュ：** 標準は 1 MiB・保存から7日間です。容量の上限を変更でき、管理画面から削除できます。

## 更新・困ったとき

アプリを新しい版へ入れ替え、管理画面から翻訳スクリプトを更新して、管理画面と問題ページを再読み込みしてください。古いスクリプトにはバーや管理画面に更新案内が出ます。Tampermonkey に旧名のスクリプトが残っている場合は無効にしてください。

- **バーが出ない：** Tampermonkey とスクリプトが有効か、「ユーザースクリプトを許可」が ON か、管理画面のサイト表示設定を確認してください。一般ページはメニューから手動で開始できます。
- **「アプリ未接続」と出る：** アプリを開き、バーの再接続アイコンを押してください。管理画面は [127.0.0.1:8765](http://127.0.0.1:8765/) です。
- **訳文が出ず原文が残る：** 数式や書式を保てない結果は適用しません。再度翻訳するか、文章を対訳ページへ貼り付けて試してください。
- **動作が重い：** 800M を選ぶ、翻訳の並列数を下げる、推論の稼働率を下げることで調整できます。

詳しい使い方は [Tampermonkey 版の説明](userscript/README.md) を参照してください。不具合報告には、OS・ブラウザー・モデル・問題ページの URL と症状を添えてください。

## 開発者向け

ソースから起動する場合は Python 3.11～3.13・[uv](https://docs.astral.sh/uv/)・Node.js が必要です。

```sh
uv sync --locked
node scripts/build_userscript.mjs
uv run plamo-cp serve
```

[管理画面](http://127.0.0.1:8765/)を開いて設定します。アプリのビルド手順は [Mac](packaging/macos/README.md)・[Windows](packaging/windows/README.md) を参照してください。
