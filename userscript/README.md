# Tampermonkey 版

PLaMo for CP アプリと Tampermonkey を使って、問題文や数式付きHTMLをこのパソコンで日本語に翻訳します。モデルはアプリのダウンロードボタンから取得します。

## 利用する

1. ブラウザーに [Tampermonkey](https://www.tampermonkey.net/) を追加する。
2. Chrome 138以降では Tampermonkey の拡張機能設定で「ユーザースクリプトを許可」を有効にする。Tampermonkey 5.3以降の要件です。手順は [公式FAQ](https://www.tampermonkey.net/faq.php?locale=ja&q=Q209) を参照してください。
3. PLaMo for CP アプリを開き、管理画面の「翻訳スクリプトをインストール」からインストールする。
4. モデルをダウンロードし、対応サイトを再読み込みする。

以前の PLaMo for CP Chrome 拡張を使っている場合は、その拡張を無効にしてからページを再読み込みしてください。古い翻訳バーとの二重表示を防げます。

Codeforces・CodeChef・CSES・Kattis・Repovive・UOJ・TLX・Project Euler には、小さな翻訳バーを表示します。UOJの中国語本文にも対応し、TLXは表示中の本文の言語に応じて翻訳します。モデルは0.8B・2B・8Bを選べ、初期モデルは2Bです。保存済みの選択は保ち、モデルの変更だけではダウンロードを始めません。

一般の記事や数式付きHTMLは、Tampermonkey のアイコンを開き、「このページを翻訳」を選びます。記事本文を優先して探し、見つからない場合はページ本体を使います。ナビゲーション・入力欄・コードブロックは除外します。ブラウザー内のPDFや設定画面はスクリプトの対象外です。ブラウザーの右クリックメニューを追加する処理はありません。

文章を貼り付けて翻訳する場合は、Tampermonkey のメニュー「テキストを翻訳」から、アプリ内の対訳ページを直接開けます。

RepoviveのMath Contest / Math Round問題では、翻訳バーの自動表示と自動翻訳を抑えます。Tampermonkeyのメニューから明示的に使う手動翻訳は制限しません。通常のRepoviveの問題ではバーを自動表示します。

arXivの `https://arxiv.org/html/*` にも、一般文書用の翻訳バーを表示します。自動翻訳は初期状態オフで、設定画面から変更できます。`/abs/` と `/pdf/` は自動表示の対象外です。

## 設定と翻訳バー

バーの歯車、または Tampermonkey の「設定・管理」から、アプリの管理画面を開けます。アプリにはモデルの保存先変更・ダウンロード・使用・削除、訳文キャッシュの容量設定があります。ブラウザー側の設定も同じ画面に表示します。

- 対応サイトの有効・無効と、ドメインやURLパターンの追加・編集・削除。例：`example.com`、`https://example.com/articles/*`。追加サイトは一般文書として扱い、実際の対応ジャッジの問題文には専用の処理を使います。
- サイトごとの「表示」と「自動翻訳」を設定できます。自動翻訳は初期状態オフで、「表示」が有効なサイトだけで動作します。対応ジャッジの問題文では、そのサイトの専用設定を使います。ブログなど問題文以外のページには、追加したURLルールの設定を使い、重なる追加ルールは上の行を優先します。CodeChef のページ内移動にも対応し、訳文の挿入や原文表示では繰り返しません。モデル未取得なら準備を案内します。旧版の一括自動翻訳がオンだった場合は、既存の有効サイトへ一度だけ引き継ぎ、個別にオフにした設定は保ちます。
- モデルごとに「同時に翻訳する段落数」を1～16から選べます。初期値は0.8Bが4段落、2Bが4段落、8Bが8段落で、保存済みの選択は保ちます。このページから未完了のまま処理する段落数の上限です。サーバー全体の処理数の制限とは独立しています。多くすると全体が早く終わる場合がありますが、一段落の表示は遅くなる場合があります。対応していない環境では保存済みの選択を消さずに1段落ずつ処理します。
- 用語集は既存の競プロ用11語を入力済みで表示し、「原語 = 訳語」の形で最大64件、合計6000文字まで編集できます。保存した一覧だけを使い、空にして保存すると用語集なしで翻訳します。旧版の追加用語は初回に初期用語へ統合し、同じ原語のユーザー指定を優先します。一般文書では初期語を除き、追加・変更した語だけを使います。アプリ内の対訳ページにも同じ一覧を反映します。

管理画面の「設定をデフォルトに戻す」で、モデル選択・サイト・自動翻訳・用語集・先行段落数・バー位置を初期値に戻せます。モデルファイルと訳文キャッシュは残ります。

つまみをドラッグすると、翻訳バーの位置を保存します。画面サイズが変わっても画面内に収めます。つまみにフォーカスして矢印キーでも移動でき、Homeキーで右下へ戻せます。

原文・訳文は翻訳の途中でも切り替えられます。原文表示中に完成した訳文は保持し、訳文表示に戻したときに表示します。処理中の段落の検証は継続し、ページ側が書き換えた文章を古い結果で上書きしません。停止しても、完成済みの段落は切り替えられます。

最初の完了は待たず、100msずつ開始をずらして設定した先行数まで増やします。長い段落は生成途中を表示できる環境では約600文字、それ以外は約300文字を目安に、数式や書式を壊さない文の境目で分けます。完成した区間は、同じ段落や依頼の残りが終わるのを待たずに表示します。完了が届くたびに先行段落数の空きを補充し、遅い段落による待ち合わせを避けます。HTMLとアプリ内の対訳ページは共通の処理を使い、約200msごとに進捗を受け取ります。MLXでは生成途中の文字列も順次表示します。途中の表示は確定訳として保存せず、完了時に数式・書式を検証します。停止・失敗時は未確定部分を原文へ戻し、完了済みの訳文を残します。

斜体・太字の本文は書式を残して翻訳します。元の文章に空白があるインライン数式・変数の境界で、モデルが空白を省略した場合だけ、小さなCSS余白を補います。訳文の文字列、TeX、数式の内部DOMは書き換えません。数式の保護で失敗した複数文の区間は、文の境目で一度だけ再試行します。数式が崩れた結果は適用しません。翻訳できなかった部分は原文のまま残し、後の段落へ進みます。まとめて翻訳する場合も段落ごとに検証します。

## 通信と保存

スクリプトはHTTP・HTTPSページで Tampermonkey のメニューを登録します。未登録の一般ページでは、メニューから翻訳を実行するまで、翻訳処理もローカルアプリへの通信も始めません。登録サイトでも自動翻訳は別の設定です。

`GM_xmlhttpRequest` の通信先は `127.0.0.1:8765` に固定し、アプリ状態・接続確認と翻訳だけに制限しています。任意URLの代理取得、外部の翻訳サービス、外部スクリプトの読み込みはありません。停止・ページ移動でリクエストを中断します。ブラウザー側の設定は Tampermonkey のストレージに保存し、値変更通知でタブ間に反映します。モデル準備完了時には、アプリのモデル選択を開いている問題ページへ反映します。

問題文は `document_type: "problem"`、一般文書は `"general"` として送ります。一般文書には競技プログラミング用の標準用語集を適用せず、ユーザー用語集はどちらでも使えます。

モデルの重みは配布物に同梱しません。ダウンロード・利用に適用されるPLaMoコミュニティライセンスは、アプリのモデル管理画面から確認できます。[契約の写し](../plamo_cp/assets/licenses/plamo-community-license-ja.txt)も収録しています。

## 開発と検証

```sh
node scripts/build_userscript.mjs
npm test
```

配布物は `dist/plamo-for-cp.user.js` です。アプリは `/install.user.js` で配信します。`browser/translator.js` の翻訳処理、`browser/settings.js` の設定画面、`browser/site-registry.js` の対応サイト・言語・利用制限、`browser/site-rules.js`、`userscript/shim.js`、`plamo_cp/assets/translation-jobs.js` の共通ジョブ処理をまとめます。対応サイトの定義は翻訳処理と管理画面で共有します。生成時にはJavaScriptの構文検証を行い、元のコアを文字列置換で壊さずに含めます。追加のパッケージ、ブラウザー、モデルは取得しません。

ブラウザーテストでは、インストール済みChrome、実HTTPのローカル模擬API、Tampermonkey APIの模擬バインディングを使います。生成物、遅延初期化、一般文書、設定共有、停止、モデル未取得、DOM保持と段落別エラーを確認します。Tampermonkey本体のインストール操作や許可画面の自動操作は行いません。
